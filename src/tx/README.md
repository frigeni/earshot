# Device-side transmitter (Profile A)

`earshot_tx.c` — the integer-only transmitter for the audible return channel
(device sings diagnostics, phone listens). See `../../spec/PROFILE-A.md` and
`../../include/earshot_tx.h`.

- No libm, no floating point, no dynamic allocation.
- Links against `../siphash.c` and `../crc.c` only.
- Builds the signed envelope, fountain-codes it, and yields one symbol per
  `earshot_tx_next()` call. The caller maps symbols to frequencies and drives
  one GPIO pin as a square wave.

`soliton_table.h` is generated by `../../tools/soliton_table.py`: a fixed-point
robust-soliton CDF, verified bit-exact against the floating-point decoder over
all 65536 possible seeds for every K in range. Regenerate with a smaller range
(`--kmax N`) to shrink it for a device that only sends short diagnostics.

The GPIO/timer glue is platform specific and lives in `../../examples/buzzer/`.
